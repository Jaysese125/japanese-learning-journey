## 📖 Overview

This repository is my personal knowledge base for learning Japanese. It combines **official coursework**, **handwritten study notes**, and **digital reference guides** into a single, well-organized archive — maintained with the same discipline I apply to software documentation.

The goal isn't just to learn a language — it's to **build a repeatable, auditable learning system** that scales from beginner to intermediate proficiency.

## 📁 Repository Structure

> *High-level overview. Individual image files and notes are stored inside their respective lesson folders.*

    japanese-learning-journey/
    ├── LICENSE
    ├── README.md
    └── Topic-1-Japanese/
        ├── Katsudoo/
        │   ├── Lesson-1-Hello/
        │   │   ├── Lesson-1-Hello.md
        │   │   └── images/
        │   └── Lesson-2-Would-you-say-that-again/
        │       ├── Lesson-2-Would-you-say-that-again.md
        │       └── images/
        └── Rikai/
            ├── Lesson-1-Hiragana/
            │   ├── Lesson-1-Hiragana.md
            │   └── images/
            └── Lesson-2-Katakana/
                ├── Lesson-2-Katakana.md
                └── images/

**Conventions:**
- One folder per curriculum module (`Topic-X-Japanese`).
- Inside each topic, separate folders for `Katsudoo` and `Rikai`.
- One Markdown file per lesson.
- Handwritten notes archived as images in the lesson's `images/` folder.
