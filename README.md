## 📖 Overview

This repository is my personal knowledge base for learning Japanese. It combines **official coursework**, **handwritten study notes**, and **digital reference guides** into a single, well-organized archive — maintained with the same discipline I apply to software documentation.

The goal isn't just to learn a language — it's to **build a repeatable, auditable learning system** that scales from beginner to intermediate proficiency.

---

## 🎯 Why This Repo Exists

| Objective | How I Approach It |
| --- | --- |
| **Structured learning** | Following an official CEFR-aligned curriculum (JF Minato / Marugoto) |
| **Consistent documentation** | Every lesson produces a Markdown reference file + handwritten notes |
| **Version control discipline** | Progress tracked commit-by-commit with clear history |
| **Reproducible methodology** | A documented system I can reuse for other languages/skills |
